# Flight Management System

## About the Project
A Java-based console application developed to manage airline operations and passenger services.

## Features
- Flight listing and seat selection
- Single and group passenger booking
- Ticket cancellation
- Dynamic fare calculation
- Passenger check-in and upgrades
- Crew management
- Flight monitoring and operations dashboard
- Safety alerts and passenger feedback

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Data Structures

## How to Run
1. Install the Java Development Kit (JDK).
2. Download the project source code.
3. Open the project in Eclipse or VS Code.
4. Compile and run `AirlineManagementSystem.java`.
